# 모아 정산 · 개인용 Windows 앱

[최신 Windows EXE 다운로드](https://github.com/haemasue-alt/moa-expense/releases/latest/download/MoaExpense.exe) · [릴리스 및 변경 내역](https://github.com/haemasue-alt/moa-expense/releases)

영수증 사진에서 사용일·사용시간·매장명·금액을 읽고, 월별 실비사용내역 엑셀과 영수증 ZIP을 만드는 개인용 프로그램입니다.

## 실행

Windows 10/11 64비트에서 MoaExpense.exe를 실행하세요. Python·Node.js·Excel 설치가 필요하지 않습니다. 처음 실행하면 사용자 폴더에 앱을 준비하고 브라우저로 화면을 엽니다.

## 사용 순서

1. 설정에서 엑셀에 표시할 조직명이나 이름을 입력합니다.
2. 사용 월을 선택하고 영수증 사진을 올립니다.
3. 날짜·시간·매장명·최종 금액을 원본과 확인하여 저장합니다.
4. 이월액·입금을 확인한 뒤 엑셀을 내려받거나 개인 정산 보관함에 저장합니다.

자료는 각 PC의 `%LOCALAPPDATA%\MoaExpense\data`에 저장됩니다. 이 폴더를 백업해주세요. 회사 로그인·메신저·다른 PC와 연결되지 않고, 영수증 사진은 OCR 서버로 보내지 않습니다.
